# Changelog

## 0.1.0 — 27 October 2026

First portable public version of Lakeside Digital's visual SEO copy review workflow.

- Reuses the refined branded before/after layout, nearby editors, explicit decisions, all-page navigation and scroll-preserving rendering.
- Prepared XLSX/CSV input, configurable branding and fictional sample data.
- Local atomic saves, revision checks, backup/restore and reviewed CSV export.
- Standard-library Python server; no AI services or runtime dependencies.
- Public setup and recreation briefs.

The client-specific source-workbook exporter is not bundled. This version exports a separate reviewed CSV and preserves exact draft strings in JSON backups.
